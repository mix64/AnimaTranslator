# Anima Prompt Translator

日本語で書いた絵の説明から、画像生成モデル **Anima** の書き方に沿った英語プロンプトを
LLM に書かせる Windows デスクトップアプリ。LLM は DeepSeek Platform か、
OpenAI 互換 API を持つローカル LLM を選べる。

- 依存パッケージなし（Python 3.9+ の標準ライブラリのみ）
- API キーは［設定］から登録し、Windows DPAPI で暗号化して保存する
- プロンプトはストリーミング表示。モデルが返す推論過程も見られる
- タグは **Danbooru の実タグに照合**し、実在するタグへ寄せる（MCP / ローカル辞書）
- 眩しくないダーク配色が既定。［設定］の「配色」でライトにも切り替えられる
- 高 DPI 対応。150% などの拡大表示でも文字がぼやけない

## 起動

`AnimaTranslator.pyw` をダブルクリックする。コンソールウィンドウは出ない。

デスクトップにショートカットを置くなら:

```bash
powershell -ExecutionPolicy Bypass -File create_shortcut.ps1
```

DeepSeek Platform を使う場合は、初回起動時に API キーの登録を促されるので、
[platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) で発行したキーを
［設定］に貼り付けて［保存］。［接続テスト］でその場に疎通確認できる。

## 使い方

左に日本語で絵の説明を入れて **Ctrl+Enter**。中央にプロンプトが流れてきたら［コピー］で Anima に貼る。
左の欄は構図・背景と、キャラクターごとの欄に分かれている。

出来上がったプロンプトを直したいときは、右上の［AI への指示］に日本語で書いて
**Ctrl+Shift+Enter**。今のプロンプトに指示を当てて作り直し、
右下の［AI の回答］に「何が原因で、どう直したか」が返ってくる。

| 操作 | 内容 |
| --- | --- |
| Ctrl+Enter | 日本語の説明からプロンプトを生成する（［AI への指示］は使わない） |
| Ctrl+Shift+Enter | 今のプロンプトに［AI への指示］を当てて作り直す |
| Esc | 中断 |
| Ctrl+A | 各欄の全選択 |

- **モデル** — DeepSeek V4.1 Flash（[API モデル名](https://api-docs.deepseek.com/) `deepseek-flash`、
  API キー必須）と、ローカル LLM のモデル。ローカル LLM のモデルは起動時と設定の保存時に
  `/v1/models` から取得する。繋がらないときは設定で選んだモデルだけが並ぶ
- **effort** — 推論強度。`low` / `high`（既定）/ `max`。選択したモデルに適用される
- **出力形式** — 下の「出力形式」を参照
- **［AI への指示］（右上）** — 今のプロンプトをどう直すかを日本語で書く欄。
  例:「髪は白にして、教会の描写はもっと具体的に」
  指示に書かれていない部分はそのまま残る。指示欄の内容は［生成］では使われないので、
  作り直しを重ねながら指示を書き換えていける。タグ行のある形式なら作り直した結果も
  Danbooru 照合を通る
- **［AI の回答］（右下）** — その指示に対して、どの記述が原因だったか、
  何に置き換えたか、あえて変えなかったものは何かが日本語で入る。
  モデルはプロンプトのあとに `WHY:` から始まる行で説明を返し、アプリが受信中に
  その前後で振り分けている（`prompts.WHY_MARKER` / `split_notes`）。
  説明は照合にも履歴のプロンプトにも混ざらない
- **［履歴］** — 直近 30 件。ダブルクリックで 4 つの欄すべてを復元できる。
  作り直した分は `[修正: …]` と指示付きで並ぶ
- プロンプト欄はそのまま編集できる

## 出力形式

| 形式 | 出力 |
| --- | --- |
| タグ＋補足文（既定） | 1 行目にタグ、空行、2〜3 文の英文。タグで描くものを決め、文で配置と動作を結ぶ |
| タグのみ | タグ 1 行だけ。関係は Danbooru の関係タグ（`eye contact` など）で書く |
| 自然文 | 英文の段落だけ。入力が作者を指定したときは、1 行目に `@作者`、空行、段落 |

タグは Anima の決まった順に並び、人数のタグから始まる。

```
[人数] [キャラクター] [作品] [@作者] [一般タグ]
```

品質・スコア・年代・メタ・レーティングのタグ（`masterpiece, best quality, score_7, safe` など）は
出力しない。入力の内容と関係なく毎回同じものを付けるタグなので、貼り付け先の側で持っておく。
入力そのものに書かれている場合だけ残す。

入力に `ネガティブ:` で始まる行があるときだけ、最後に `negative: ...` の行が付く。

## プロンプトの書き方の定義

`prompts.py` と `anima/prompting-en.txt` にすべて書いてある。

- `prompts.py` — 役割と出力の決まり（`WRITE_TASK`）、出力形式ごとのレイアウト（`STYLES`）、
  手本（`_EXAMPLES`）、作り直しと照合のプロンプト。手本は 1 つの場面を 3 形式で書いたもので、
  選んだ形式に合わせて組み立てる
- `anima/prompting-en.txt` — Anima の語彙と文の書き方。タグの順序と表記、
  日本語の言い回しに対応する Danbooru タグ、文の書き方、足してよいもの・いけないもの。
  出典は `anima/README.md`

強調構文 `(tag:1.2)`、`<lora:name:0.8>`、`BREAK`、ワイルドカード、固有名詞、数値はそのまま残す。

DeepSeek は混雑時に 503（Service is too busy）を返すことがある。本文が届く前の
失敗（503 / 500 / 502 / 504 / 429 / 接続エラー）は 2 秒・5 秒・12 秒と待って
自動で投げ直し、経過をステータス行に出す。4 回目も失敗したときだけエラーにする。
流れ始めてからの切断は、投げ直すと本文が二重になるので再試行しない。

出力の癖を直したいときは `prompts.py` か `anima/prompting-en.txt` を編集してアプリを再起動する。
一時的な調整だけなら［設定］の「追加指示」で足りる。

## 設定

［設定］は 3 つのタブに分かれている。

**接続**

- **DeepSeek Platform の API キー** — ［接続テスト］は DeepSeek Platform に対して確かめる。
  DeepSeek のモデルを選んでいるときは、キーが空のままでは保存できない
- **ローカル LLM** — OpenAI 互換 API のサーバー
  - ベース URL: `/v1` まで書く。既定値は `.env` の `ANIMA_LOCAL_URL`。
    アプリはこの後ろに `/chat/completions` と `/models` を付けて使う
  - API キー（任意）: サーバーがキーを求めるときだけ書く。DeepSeek のキーと同じく暗号化して保存する
  - モデル: 一覧から選ぶか、モデル ID を直接書く。
    ［接続してモデル一覧を取得］で、欄に書いた URL とキーのまま `/models` に問い合わせ、一覧を埋める。
    キーが違うと 401 になり、API キーを確かめるよう表示する
  - モデル欄が空でないまま保存すると、そのモデルが選ばれ、メイン画面のモデル一覧にも並ぶ
- **Danbooru MCP** — 既定値は `.env` の `ANIMA_MCP_URL`。空なら使わない。
  接続できれば全タグを照合し、接続できなければローカル CSV 辞書へ自動で戻る

**プロンプト**

- **追加指示** — 毎回のシステムプロンプトに足す常設の指示。例:「補足文は 2 文までにする」
  こちらは常設で、［AI への指示］はその場かぎり

**表示**

- **配色** — ダーク（既定）/ ライト。保存した瞬間に反映され、
  入力中の内容もそのまま残る。Windows のタイトルバーも配色に合わせて明暗が変わる
- **フォント** — 既定は自動（Yu Gothic UI・Meiryo UI・Segoe UI のうち入っているもの）
- **保存先** — 設定ファイルの場所と、そのフォルダを開くボタン

## Danbooru タグへの寄せ

「タグ＋補足文」と「タグのみ」では、生成のあとに照合パスが走る。
照合するのはタグの行だけで、「タグ＋補足文」の英文と `negative:` 行は対象外。
設定した Danbooru MCP に接続できれば全タグを使い、接続できなければ
`tags/danbooru.csv` に自動で戻る。辞書で決定論的に置換するのではなく、
**辞書は実在と一般度だけを答え、
寄せるかどうかは LLM が判断する**。ニュアンスを潰さないための分担。

1. タグを MCP または `tags/danbooru.csv` に当てて 3 つに分ける
   - 実在して `post_count` が 100 以上 → そのまま
   - 実在するが 100 未満（学習例が少なく反応しにくい） → 再照会
   - 実在しない → 再照会
2. 再照会するタグにだけ、構成語が重なる実タグを post_count 付きで候補として渡し、
   「意図が保てるものがあれば選べ。無ければ原語のまま」と判断を委ねる。
   1 タグを複数タグに割ってもよい（`shy smile` → `light smile, blush`）
3. 返ってきた寄せ先を辞書で再検証し、実在するものだけ差し替える

出力欄の色で結果が分かる。

| 表示 | 意味 | 操作 |
| --- | --- | --- |
| 緑 | Danbooru の実タグに寄せた | カーソルを乗せると元の語、右クリックで戻せる |
| 赤 | Danbooru に無いまま残した | カーソルを乗せるとその旨を表示 |

- 別名と下線表記（`longhair` → `long hair`、`blue_eyes` → `blue eyes`）は
  意味が変わらないので、色を付けずに直す。
- Anima の制御用の語は、入力に書かれていて出力に残った場合も照合しない。品質の語（`masterpiece`、`best quality` など）、
  `score_7` のようなスコア、`year 2024` と年代の語（`newest` など）、4 つのレーティング、
  `@作者` は Danbooru の語彙ではないので、辞書にも LLM にも回さず、書かれたまま残す。
- 名前の一部の括弧は、強調構文と区別するため `fern \(sousou no frieren\)` と逃がして書く。
  照合では逃がしを外した `fern (sousou no frieren)` で辞書を引き、実在すれば
  逃がした形で書き戻す。実在しなければほかのタグと同じく再照会し、
  修飾を外した名前（`frieren`）が辞書にあれば候補に加える。
  寄せ先に括弧が含まれるときも、逃がした形で書き込む。
- `(tag:1.2)` や `(tag)` の強調構文、`<lora:...>`、`BREAK`、ワイルドカードは照合対象から外れる。
- 追加の API 呼び出しは、寄せる候補がある場合の 1 回だけ。無ければ 0 回。
- タグ表が無い環境では照合を丸ごと省略し、生成結果をそのまま出す。

## タグ表の取得と更新

`tags/danbooru.csv` に post_count 上位 10 万タグと別名 4 万件が入っている（2.5MB）。
作り直すには:

```bash
python refresh_tags.py
```

Danbooru の読み取り API（キー不要）から post_count 上位 10 万タグと別名を取り、
`tags/danbooru.csv` を作る。数分かかる。件数を減らすならページ数を渡す
（`python refresh_tags.py 30` で上位 3 万タグ）。

キャラクタータグや作品タグは増え続けるので、古くなったら再実行すればよい。

## 接続先の既定値（.env）

ローカル LLM と Danbooru MCP の URL は環境ごとに違うので、コードには書かず `.env` に置く。
`.env.example` を `.env` にコピーして値を書く。`.env` は git に入らない。

```
ANIMA_LOCAL_URL=http://localhost:8000/v1
ANIMA_MCP_URL=
```

- 置き場所は `AnimaTranslator.pyw` と同じフォルダ。`.exe` で使うときは `.exe` と同じフォルダ
- 同じ名前の環境変数があれば、そちらが `.env` より優先される
- ここの値は既定値で、［設定］で保存した値があればそちらが使われる
- `.env` が無くても動く。その場合はどちらも空になり、［設定］で入力する

## 設定の保存先

```
%APPDATA%\AnimaPromptTranslator\config.json
```

DeepSeek の API キーは `api_key_enc`、ローカル LLM の API キーは `local_api_key_enc` として
Windows DPAPI（現在の Windows ユーザ専用）で暗号化される。
別ユーザや、ファイルを持ち出した先では復号できない。
設定に DeepSeek のキーが無い場合は環境変数 `DEEPSEEK_API_KEY` にフォールバックする。

## テスト

```bash
python -m unittest discover -s tests
```

テストは実際の設定ファイルを読み書きしない。

## 単体の .exe を作る

Python が入っていない PC にも配りたい場合:

```bash
build_exe.bat
```

初回のみ PyInstaller を導入し、`dist\AnimaTranslator.exe` を作る（要インターネット接続）。
`.exe` があれば `create_shortcut.ps1` はそちらを指すショートカットを作る。

## ファイル構成

```
AnimaTranslator.pyw   GUI 本体（これを起動する）
deepseek.py           OpenAI 互換 Chat API クライアントと接続先の解決
prompts.py            システムプロンプト、手本、出力の形の解釈
anima/                Anima のプロンプトの書き方（prompting-en.txt）と出典
grounding.py          Danbooru タグへの寄せ（照合パスの段取り、制御語と括弧の扱い）
mcpdict.py            Danbooru MCP クライアント兼タグ辞書
tagdict.py            タグ表の索引。実在と一般度の判定、候補の列挙
refresh_tags.py       Danbooru からタグ表を取得して tags/danbooru.csv を作る
tags/danbooru.csv     タグ表（name, category, post_count, aliases）
config.py             設定の保存・読み込み、.env の読み込み、DPAPI 暗号化
.env.example          接続先の既定値の雛形（.env にコピーして使う）
tests/                回帰テスト
build_exe.bat         .exe を作る
create_shortcut.ps1   デスクトップにショートカットを作る
```
